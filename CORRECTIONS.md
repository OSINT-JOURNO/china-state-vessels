# Corrections

If a row is wrong (a renamed or sold ship, a wrong identifier, a label a source has withdrawn, or a vessel that
should not be here), please open an issue with the vessel's ID and a source for the correction.

Corrections are checked against the source and published with a dated note in this file. Removed rows are listed here
with the reason, so anyone who used an earlier version can see what changed.
